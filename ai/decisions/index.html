⚖️ How On-Device Decisions Scoring Works

DecisionModel compiles each question's candidate options into single-token keys ("A".."Z"), prefills the shared prompt prefix once, and scores each option's next-token logit using max-shifted softmax (P(t) = exp(z_t - z_max) / sum_j exp(z_j - z_max)). For score questions, it also computes the probability-weighted expectedScore.
