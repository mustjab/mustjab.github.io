Concurrency Scaling

🔀 Can Overlapping Calls Recover the Per-Call Cost?

Every translate() call pays a fixed dispatch cost that does not scale with input length, so short segments are dominated by overhead. This test replays the page corpus through 1, 2, 4 and 8 overlapping calls. A speedup above 1x means that cost is partly recoverable today without batched inference. A flat 1x means the API serializes translate() and only true batching will help.
